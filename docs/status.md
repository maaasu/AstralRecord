# ステータスシステム詳細仕様

> AstralRecord のプレイヤーステータスシステムに関する詳細仕様書です。
> ソースコード上の定義: `feature/status/model/StatusType.kt`

---

## 概要

プレイヤーは **29 種類** のステータスを持ち、レベル・装備・バフ・職業などにより値が変動します。
ステータスは以下の 5 カテゴリに分類されます。

| カテゴリ    | 列挙名 (Category) | 含まれるステータス数 | 概要                           |
|:--------|:---------------|:-----------|:-----------------------------|
| リソース    | `RESOURCE`     | 3          | HP / MP / エネルギーの最大値          |
| 基本能力値   | `PRIMARY`      | 6          | 攻撃スケーリング・派生ステータスの元値          |
| 攻撃      | `OFFENSE`      | 13         | 攻撃力・攻撃種別・会心・超会心・最終ダメージ・命中・速度 |
| 防御      | `DEFENSE`      | 3          | 物理防御・魔法防御・回避                 |
| ユーティリティ | `UTILITY`      | 4          | 回復・移動速度・クールダウン短縮             |

---

## リソースシステム（HP / MP / エネルギー）

プレイヤーは 3 種類のリソースを持ちます。
現在値は `StatusSnapshot` で管理され、最大値は `StatusType` のステータス計算で決定します。

| リソース   | 最大値ステータス    | 回復ステータス      | 用途                    |
|:-------|:-----------|:-------------|:----------------------|
| HP     | `MAX_HEALTH` | `HP_REGEN`   | 生存判定。0 で戦闘不能          |
| MP     | `MAX_MANA`   | `MP_REGEN`   | 魔法・スキル発動コスト           |
| エネルギー  | `MAX_ENERGY` | `ENERGY_REGEN` | ダッシュ・回避行動・特殊スキル発動コスト |

---

## 攻撃種別と職業スケーリング

### 設計方針

- **武器には「攻撃力（ATTACK）」のみ** をステータスとして持たせます。
- 攻撃種別ごとの最終攻撃力（`MELEE_ATTACK` / `RANGED_ATTACK` / `MAGIC_ATTACK`）は
  `ATTACK` と対応する基本能力値からスケーリング計算によって導出されます。
- これにより、同じ武器でも職業によって異なるダメージが出力される仕組みとなります。
- **攻撃種別は `StatusType` として定義** されているため、バフ・装備で個別に強化可能です。

### 攻撃種別

| 攻撃種別 | StatusType       | スケーリング能力値          | 武器例        |
|:-----|:-----------------|:-------------------|:-----------|
| 近接攻撃 | `MELEE_ATTACK`   | 筋力（`STRENGTH`）     | 剣・斧・槍      |
| 間接攻撃 | `RANGED_ATTACK`  | 器用さ（`DEXTERITY`）   | 弓・クロスボウ・投擲 |
| 魔法攻撃 | `MAGIC_ATTACK`   | 知力（`INTELLIGENCE`） | 杖・魔導書・オーブ  |

### 攻撃種別の計算式

```
MELEE_ATTACK  = ATTACK × (1 + STRENGTH × スケーリング係数_STR)
RANGED_ATTACK = ATTACK × (1 + DEXTERITY × スケーリング係数_DEX)
MAGIC_ATTACK  = ATTACK × (1 + INTELLIGENCE × スケーリング係数_INT)
```

- **スケーリング係数** は職業ごとに異なる定数（将来の職業システムで定義）。
- バフや装備で `MELEE_ATTACK` 等を直接加算することも可能。

## ダメージ計算フロー

```
1. 攻撃種別に応じた最終攻撃力を取得
   └─ MELEE_ATTACK / RANGED_ATTACK / MAGIC_ATTACK

2. 命中判定
   └─ ACCURACY vs 対象 EVASION → ミス時はダメージ 0

3. 基本ダメージ算出
   └─ 最終攻撃力 × スキル倍率 × 属性補正

4. 会心判定
   ├─ CRITICAL_RATE で会心判定
   ├─ 会心時: ダメージ × (CRITICAL_DAMAGE / 100)
   └─ 超会心判定（会心時のみ）
      ├─ SUPER_CRITICAL_RATE で超会心判定
      └─ 超会心時: ダメージ × (SUPER_CRITICAL_DAMAGE / 100)

5. 防御補正
   ├─ 物理攻撃: DEFENSE による軽減
   └─ 魔法攻撃: MAGIC_DEFENSE による軽減

6. 最終ダメージ判定
   ├─ FINAL_DAMAGE_RATE で発動判定
   └─ 発動時: ダメージ × (FINAL_DAMAGE_MULTIPLIER / 100)

7. バフ・デバフ補正
   └─ 最終ダメージに乗算/加算
```

### ダメージ計算の概念式

```
最終ダメージ = 攻撃種別攻撃力 × スキル倍率 × 属性補正
            × 会心補正 × 超会心補正 × 防御補正
            × 最終ダメージ補正 × バフ補正
```

## 会心・超会心・最終ダメージシステム

### 会心（Critical Hit）

通常攻撃・スキル攻撃時に `CRITICAL_RATE`% の確率で発動し、
ダメージに `CRITICAL_DAMAGE / 100` 倍率を乗算します。

| ステータス           | 初期値   | 説明                     |
|:----------------|:------|:-----------------------|
| `CRITICAL_RATE`   | 5.0%  | 会心が発生する確率              |
| `CRITICAL_DAMAGE` | 150.0% | 会心時のダメージ倍率（1.5倍）       |

### 超会心（Super Critical Hit）

**会心が発生した場合にのみ** 追加で `SUPER_CRITICAL_RATE`% の確率で判定される第二の会心です。
発動すると、会心ダメージにさらに `SUPER_CRITICAL_DAMAGE / 100` 倍率が乗算されます。

| ステータス                 | 初期値   | 説明                       |
|:----------------------|:------|:-------------------------|
| `SUPER_CRITICAL_RATE`   | 0.0%  | 会心時に超会心が発動する追加確率         |
| `SUPER_CRITICAL_DAMAGE` | 200.0% | 超会心時に会心ダメージへ追加乗算される倍率（2.0倍）|

**計算例（超会心発動時）:**
```
基礎ダメージ: 100
会心ダメージ: 100 × (150 / 100) = 150
超会心ダメージ: 150 × (200 / 100) = 300
```

### 最終ダメージ（Final Damage）

全てのダメージ計算が完了した後、`FINAL_DAMAGE_RATE`% の確率で発動する追加ダメージボーナスです。
会心・超会心とは独立した判定であり、会心の有無にかかわらず発動する可能性があります。

| ステータス                   | 初期値   | 説明                     |
|:------------------------|:------|:-----------------------|
| `FINAL_DAMAGE_RATE`       | 0.0%  | 最終ダメージ補正が発動する確率        |
| `FINAL_DAMAGE_MULTIPLIER` | 130.0% | 発動時の倍率（1.3倍のダメージ）      |

**計算例（最終ダメージ発動時）:**
```
防御補正後ダメージ: 120
最終ダメージ: 120 × (130 / 100) = 156
```

| `DEXTERITY`    | 器用さ | —  | 0   | 5.0 | 間接攻撃（弓・投擲等）のダメージスケーリングに影響    |
| `INTELLIGENCE` | 知力  | —  | 0   | 5.0 | 魔法攻撃のダメージスケーリング・最大MP・MP回復に影響 |
| `VITALITY`     | 体力  | —  | 0   | 5.0 | 最大HP・物理/魔法防御・HP回復に影響         |

| `LUCK`         | 幸運  | —  | 0   | 5.0 | 会心率・ドロップ率に影響                 |

| `AGILITY`      | `ATTACK_SPEED`、`MOVEMENT_SPEED`、`EVASION`         |
| `LUCK`         | `CRITICAL_RATE`、ドロップ率（アイテムドロップシステム側で参照）           |

### 防御系（DEFENSE）

| 列挙名             | 表示名   | 単位 | 小数桁 | 初期値 | 説明                  |
|:----------------|:------|:---|:----|:----|:--------------------|
| `DEFENSE`       | 物理防御力 | —  | 0   | 5.0 | 近接・間接攻撃による物理ダメージを軽減 |
| `MAGIC_DEFENSE` | 魔法防御力 | —  | 0   | 3.0 | 魔法攻撃によるダメージを軽減      |
| `EVASION`       | 回避率   | %  | 1   | 3.0 | 攻撃を完全に回避する確率        |

#### 防御計算の概念

```
物理ダメージ軽減率 = DEFENSE / (DEFENSE + 定数A)
魔法ダメージ軽減率 = MAGIC_DEFENSE / (MAGIC_DEFENSE + 定数B)
```

- 定数 A・B はレベル帯によって調整されるバランスパラメータです。
- `EVASION` は `ACCURACY` との対抗判定で、回避成功時はダメージが 0 になります。

### ユーティリティ系（UTILITY）

| 列挙名                  | 表示名   | 単位 | 小数桁 | 初期値   | 説明                           |
|:---------------------|:------|:---|:----|:------|:-----------------------------|
| `HP_REGEN`           | HP回復力 | —  | 0   | 1.0   | 5秒ごとに自然回復するHP量               |
| `MP_REGEN`           | MP回復力 | —  | 0   | 0.5   | 5秒ごとに自然回復するMP量               |
| `ENERGY_REGEN`       | EN回復力 | —  | 0   | 5.0   | 5秒ごとに自然回復するエネルギー量            |
| `MOVEMENT_SPEED`     | 移動速度  | %  | 0   | 100.0 | 移動速度の割合。100% が標準速度           |
| `COOLDOWN_REDUCTION` | CD短縮  | %  | 1   | 0.0   | スキルのクールダウン短縮率。上限あり（要バランス調整）  |

#### 補足

- `HP_REGEN` / `MP_REGEN` / `ENERGY_REGEN` の回復間隔は **5秒** を基本周期とします。
- `COOLDOWN_REDUCTION` の上限値はバランス調整の対象であり、40〜50% 程度を想定しています。

## ステータス計算の流れ

プレイヤーのステータスは `StatusService` により以下の順序で計算されます。

```
1. ベース値（getBaseValue）
   └─ 全ステータスの初期値を返す

2. ボーナス値（getBonusValue）
   ├─ アカウントモード補正（PLAYER / BUILDER / ADMIN）
   ├─ 権限レベル補正
   ├─ バフ補正（ActiveBuff の加算・乗算を適用）
   └─ ※将来: レベル補正、装備補正、パッシブスキル補正、
              攻撃種別の ATTACK × PRIMARY スケーリング算出

3. 合計値
   └─ totalValue = baseValue + bonusValue

4. StatusSnapshot 生成
   └─ 全 StatusType の StatusValue を Map に格納し、
      currentHp / currentMp / currentEnergy / 計算日時とともにスナップショット化
```

### StatusValue の構造

```kotlin
data class StatusValue(
    val baseValue: Double,   // ベース値
    val bonusValue: Double,  // 全補正の合計
) {
    val totalValue: Double   // = baseValue + bonusValue
}
```

### StatusSnapshot の構造

```kotlin
data class StatusSnapshot(
    val values: Map<StatusType, StatusValue>,
    val currentHp: Double,       // 現在HP
    val currentMp: Double,       // 現在MP
    val currentEnergy: Double,   // 現在エネルギー
    val calculatedAt: LocalDateTime,
)
```

## 外部システム連携

### マスタデータ（YAML）

アイテム定義（武器）の YAML では、`ATTACK` のみをステータスとして記述します。

```yaml
# 武器マスタデータの例
weapon_iron_sword:
  name: "鉄の剣"
  attack_type: MELEE       # 近接攻撃 → MELEE_ATTACK で計算
  stats:
    ATTACK: 12             # 武器が持つ唯一のステータス
```

### AstralRecord API

ステータス関連のデータは以下のエンドポイントで参照されます。

- **バフ定義**: `/api/buff` — バフごとに影響する `StatusType` と加算値/乗算率を返却
- **アイテム定義**: `/api/item` — 武器の `ATTACK` 値を含むアイテム情報を返却

### データベース

プレイヤーのステータスは `StatusSnapshot` としてメモリ上で管理され、
セッション中にリアルタイムで計算・更新されます。永続化が必要な場合は SQL Server に保存します。
