## 依存の原則

```mermaid
graph LR
    F["feature"] -->|使用可| C["core"]
    F -->|使用可| I["infrastructure"]
    C -->|使用可| I
    I -. "禁止" .-> C
    I -. "禁止" .-> F
    C -. "禁止" .-> F
```

| ルール | 理由 |
|:------|:----|
| `infrastructure` は `core` / `feature` に依存しない | 基盤層が上位ゲームロジックを知ると循環依存が生まれる |
| `core` は `feature` に依存しない | フレームワーク層が具体的な機能を知るべきではない |
| `feature` はすべての下位層を使用できる | ゲームロジックは基盤サービスを自由に組み合わせる |
