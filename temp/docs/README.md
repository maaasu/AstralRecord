# AstralRecord — ドキュメント一覧

本ディレクトリは、AstralRecord プラグインのアーキテクチャ・機能構造を Mermaid 図で視覚化したドキュメント群です。  
設計書の代わりに、コードと常に対になる参照資料として維持・更新してください。

---

## ドキュメント構成方針

| 種別               | 内容                                 | 更新タイミング              |
|:-----------------|:-----------------------------------|:----------------------|
| `architecture/`  | プラグイン全体の構造・依存関係・起動フロー             | パッケージ構成や初期化フローを変更したとき |
| `infrastructure/` | 基盤層（DB・ロギング・設定）の詳細な機能構造           | 該当クラスの責務や関係を変更したとき    |
| `core/`          | コアシステム（イベント・コマンド）の構造              | 該当クラスの責務や関係を変更したとき    |
| `feature/`       | 機能層（アイテム・プレイヤー・インベントリ）の詳細構造      | 機能を追加・変更したとき          |

## Mermaid 記法について

各ドキュメントは [Mermaid](https://mermaid.js.org/) を使用しています。  
GitHub や JetBrains IDE (Markdown プレビュー) でレンダリング可能です。

使用している図の種類:

| 記法              | 用途                    |
|:----------------|:----------------------|
| `graph TD`      | クラス間・モジュール間の関係（上→下）   |
| `sequenceDiagram` | 処理フロー・メソッド呼び出し順序     |
| `classDiagram`  | クラス定義・継承・実装関係         |
